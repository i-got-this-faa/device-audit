At a 15-second requested start-to-start cadence, sweep wall times were
6.821, 6.765 and 6.724 seconds. Sum of worker CPU per sweep was 5.797, 5.469
and 5.313 CPU-seconds. Peak individual worker working set was 98.58 MiB.
At a 60-second cadence, sweep wall times were 8.056, 15.397 and 9.022 seconds;
worker CPU sums were 6.297, 8.922 and 7.156 CPU-seconds, with a 99.68 MiB
maximum worker peak. No sweep overran its requested cadence and no worker
hit its 10-second deadline. Thermal denials did not stop later GPU/event probes.

The second run overlapped dependency compilation; workload was not controlled
or equal between runs. These numbers do **not** establish that a longer cadence
makes each sweep faster or cheaper. CPU sums include PowerShell startup but
exclude the coordinator, WMI provider hosts and NVIDIA subprocess. Worker peaks
are sequential, not simultaneous. There is no full-system overhead result.

For continued **development probing**, use 60 seconds rather than high-rate
process launches, and retain the 10-second source deadline. Even the first run
spends about seven seconds launching/querying eight independent processes per
sweep; that design should not become a production one-second collector. A future
persistent Go collector needs independent cost, cadence and service-token tests.
No production resource budget, threshold or service privilege is approved here.

### Additional native networking blocker

The in-review Tailcat lab from PR #168 at
`9cd99a1941cb26395a5f20ba4894d6ddfde129f5` was checked separately, without
changing its branch. Its nested module downloaded and compiled natively. Running
`go test -run '^TestStateFailsClosed$' -count=1 -timeout=150s .` failed at
`state_test.go:37`: `network state requires an existing regular 0600 file, at most 4096 bytes`.
Windows does not express a private DACL as Unix mode 0600. The failure occurs
before any direct-transport proof. No Windows transport success is claimed.
Secure Windows state creation and ACL validation plus appropriate negative
tests are needed before native lab qualification; dropping the private-state
check is not sufficient. The Linux lab and production mesh remain separate.
